## 3.1. Общие правила

Формулы пишутся на **SpEL (Spring Expression Language)**, как требует ТЗ §5.4.

| Правило | Описание |
|---|---|
| 🔗 **Ссылка на тег** | `#ИмяТега` — имя берётся из колонки `tagName` (без префиксов). <br>Пример: `#Tank1_Level * 2.5` |
| ✅ **Доступность** | Ссылаться можно только на **включённые** теги. Циклические зависимости обнаруживаются валидатором и отклоняются (ТЗ §5.4.5) |
| 🎯 **Качество результата** | `Good` — если **все** входы `Good`; иначе `Bad`. При недоступности входа значение результата = `null` (ТЗ §5.4.6) |
| 🧩 **Тип результата** | Определяется колонкой `dataType`. При несовместимости — `Bad_Configuration` (например, строку нельзя в `BOOLEAN`) |
| 🔢 **Литералы** | • Числа: `42`, `3.14` <br>• Строки: `'HIGH'` (в одинарных кавычках) <br>• Логические: `true` / `false` <br>• Null: `null` |
| ⏱ **Период пересчёта** | Период CALC-тега = его `refreshPeriodMs`. Должен быть **≥** минимального периода его входов |

## 3.2. Операторы

| Категория | Операторы | Пример |
|---|---|---|
| **Арифметика** | `+` `-` `*` `/` `%` | `#A * 2.5 + #B % 10` |
| **Сравнение** | `>` `<` `>=` `<=` `==` `!=` | `#Level >= 80` |
| **Логика** | `and`, `or`, `not` (или `&&`, `||`, `!`) | `#A and not #B` |
| **Тернарный** | `условие ? тогда : иначе` (вложение допустимо) | `#L > 80 ? 'HIGH' : 'OK'` |
| **Элвис (null-safe)** | `значение ?: дефолт` | `#OptTag ?: 0` |
| **Конкатенация строк** | `+` | `'Level=' + #Level` |
| **Степень** | `^` | `#X ^ 2` |

## 3.3. Частые рецептуры

| Задача | Формула |
|---|---|
| **Масштабирование сырого значения** | `#Raw * 0.1 + 5` |
| **Гистерезис через два порога** | `#Level > 85 ? true : (#Level < 75 ? false : null)` |
| **Диапазон «в норме»** | `#T >= 18 and #T <= 25` |
| **Мультитревога** | `#High or #Low or #SensorFail` |
| **Текст из кода** | `#Code == 1 ? 'HIGH' : (#Code == 2 ? 'LOW' : 'OK')` |
| **Дельта двух дат (мин)** | `T(java.time.Duration).between(#T1, #T2).toMinutes()` |

> ⚠️ **Примечание по `null`**  
> Если вход `Bad`, ссылка на него в формуле даёт `null`. Арифметика с `null` даст ошибку вычисления → `Bad_CommunicationFailure` у CALC-тега.  
> Для «мягкой» деградации используйте **Элвиса**: `#Level ?: 0` (0 при недоступности входа) или тернарник с явной проверкой.

## 3.4. Встроенные функции (через type-reference `T(...)`)

SpEL даёт доступ к статическим методам Java:

| Задача | Формула |
|---|---|
| **Модуль** | `T(java.lang.Math).abs(#X)` |
| **Округление** | `T(java.lang.Math).round(#X)`, `T(java.lang.Math).floor(#X)`, `ceil` |
| **Мин / макс** | `T(java.lang.Math).max(#A, #B)` |
| **Степень / корень** | `T(java.lang.Math).pow(#X, 3)`, `sqrt` |
| **Тригонометрия / лог** | `sin`, `cos`, `log`, `exp` |
| **Строки** | `#S.toUpperCase()`, `#S.length()`, `#S.contains('ALARM')` |
| **Число из строки** | `T(java.lang.Double).parseDouble(#S)` |

> 🔒 **Безопасность:** на этапе 3 в `SpelCalcEngine` будет использоваться `SimpleEvaluationContext` — доступ только к тегам и перечисленным классам (`Math`, `Double`, `Duration`…), **без вызова произвольных типов и конструкторов** (ТЗ §7.2).

## 3.5. Приведение типов

- **Явный cast** — методом:

  ```spel
  #Level.intValue()
  #Count.doubleValue()
  #Flag.toString()
  ```

- **Неявно:** SpEL приводит число к целевому `dataType` результата, если это возможно:
    - `DOUBLE`-тег из целого выражения — ✅ ок
    - `BOOLEAN` из числа — ❌ нет, пишите сравнение явно: `#X != 0`

- **DATETIME:**
    - Сравнение операторами — ✅ ок: `#T1 > #T2`
    - Арифметика — **только** через `Duration` (см. выше)

## 3.6. Ошибки и их диагностика

| Симптом | Причина |
|---|---|
| `Bad_Configuration` | Ссылка на несуществующий тег; синтаксис; циклическая зависимость; несовместимый `dataType` |
| `Bad_CommunicationFailure` при `Good`-входах | Исключение при вычислении (деление на ноль, cast) — смотрите лог `SpelCalcEngine` |
| Результат «завис» | Вход тега выключен (`enabled=false`) — выключенные входы не участвуют |
| Всё `null` у CALC | Все входы `Bad` — так и задумано (§5.4.6) |

## 3.7. Ограничения (будут зашиты в валидатор)

| Ограничение | Значение |
|---|---|
| Глубина цепочки `CALC → CALC` | **≤ 10** (ТЗ §5.4.5) |
| Длина формулы | **≤ 2000 символов** |
| Запрещено | `new`, `T()` на классы вне белого списка, доступ к бинам (`@bean`), `System.*` |
